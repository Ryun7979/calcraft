# 引き継ぎ：マシマシモード v2「もっと派手に」（2026-10-18）

ユーザーの追加依頼：もっと派手に／タイトル画面も動いて派手に／女の子キャラを作って二人で盛り上げる／キャラを大きく／ゾンビを主人公がやっつける演出／〇分で何問のチャレンジモード。

## やったこと
- **キャラ**：`src/lib/hype/blockun.ts` → `characters.ts` に作り直し（スキン方式）。ブロッくん・**ブロッちゃん**（新）・**ゾンビ**（新）。
  動きに「パンチ（腕が届く長さまで伸びる）」「ビーム」「ゾンビ歩き・やられ・わらい」を追加。viewBox を詰めて大きく見えるように。
  React 部品は `Blockun.tsx` → `PixelChar.tsx`（`who` で切り替え）。
- **たたかいの場** `BattleField.tsx`：2人＋ゾンビ。正解でやっつける、まちがいでゾンビがわらう、FEVER で群れ。ふきだしは2人。タイトルではデモで自動戦闘。
- **演出**：`FxCanvas` に衝撃波の輪・虹のビーム・ギザギザ文字（ドカッ!）を追加。パーティクル上限を倍に。FEVER 中の虹色背景。効果音（パンチ・ビーム・ヒット・時計・TIME UP）を追加。
- **タイトル画面** `HypeMenuScreen.tsx` を作り直し：ブロックがふる背景（`BlockRain.tsx`）、はねる虹ロゴ、テープ、デモ戦闘、花火、背景クリックで花火、光るスタートボタン、れんしゅう／チャレンジの切り替え。
- **チャレンジモード**：設定 `playMode` / `challengeMinutes`、`useGame` に `endGame()` を追加、HUD に時計、TIME UP のカットイン、結果画面の「○ぷんで ○もん せいかい！」と自己ベスト（点数・正解数）。ランクは目安のペースからの満点で決める（`docs/spec.md` §4.8・§7）。
- 結果画面：2人を左右に大きく、ゾンビをやっつけた数。
- `scripts/autoplay.js`：チャレンジの結果画面にも対応。時間切れと同時の答えは数えない。
- `scripts/simulate.ts`：チャレンジの試算を追加。

## 確認したこと
- `npm run lint` / `npm run build` が通る。外部 URL はビルドに含まれない（React のエラー案内の文字列と Tailwind のコメントだけ）。
- 聖域の自動チェック（すべて `ok: true`）：
  - れんしゅう たしざん Lv1 10問（まちがい2・先打ち3）
  - チャレンジ 1ぷん かけざん Lv5（受け付け 53問・まちがい8・先打ち13・入力欄のふさがり 0／1,793 サンプル）
  - わりざん Lv6 あまりあり 10問・演出のつよさ ひかえめ（大きなカットイン 0）
- チャレンジの時計がカウントダウン・カットイン中に止まること（1ぷんが実時間で約 92 秒＝カウント 3.2 秒＋TIME UP 2 秒＋カットイン）。
- ひかえめモードは従来どおり（4問・演出レイヤーなし・時計なし）。コンソールエラーなし。
- ブラウザで目視（1280×720 は縮小表示、細部は 580×676）：タイトルのデモ戦闘・ロゴ、コンボのカットイン（2人）、ゾンビをやっつける「バキッ!」「やっつけた!」、FEVER ×8 の帯と群れ、チャレンジの時計と結果。
