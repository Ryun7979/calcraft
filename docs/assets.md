# 素材の台帳（Gemini 製）

マシマシモードで使っている絵と音のうち、Google Gemini の **Web 画面**で作ったものの記録。API は使っていない（`docs/hade-mashimashi-playbook.md` §8）。
作り方の手順は `.claude/skills/gemini-assets/SKILL.md`。元の絵（JPEG）と未採用のものは `_inbox/`（git 管理外）にある。

- 作った日：2026-10-18（段階1：背景の柄・パーティクルの粒・ふきだしと札の枠・キャラの決めポーズ／段階2：ブロック文字・カプセル・カットインの背景）
- 加工はすべて加工台 `scripts/asset-lab/`（`node scripts/asset-lab/server.mjs` → http://127.0.0.1:5199/）で行った。
  - Gemini のダウンロードは **JPEG**（2048×2048 前後）。ドット絵として使うため、**1マスの中央 40〜50% の平均色**で本物のドットに縮める（`pixelate`）。
  - 透過は「白い背景＋濃いふち」で頼み、ふちから白をたどって消す（`cutout`、tol 30〜40）。半透明は 110 を境に 0 か 255 にする（`hardAlpha`）。
  - ドットの大きさは、色の変わり目の間かくのいちばん多い値で見つける（加工台の `dotSize`）。
- 置き場所と読みこみ：`src/assets/hype/{tiles,parts,ui,pose}/`、`src/lib/hype/assets.ts`。

## 共通の頼み方

- 1枚ごとに新しいチャット（キャラの2枚目だけは、見本の絵を引き継ぐため同じチャット）。
- 小さなものは 2×2 のシート1枚で頼み、「4枚の間は白い余白で大きく離し、ます目の線は描かない」と書く。
- ドット絵は「16×16ドットのピクセルアートで、1ドットがくっきりした大きな正方形に見えるように」「ぼかし・グラデーション・影・文字・枠線は入れない」と書く。

## 7. カットインの背景（`src/assets/hype/ui/shatter.png`、段階2）

```
画像を作成してください。横長の画像（16:9）で、真っ白な背景に、ブロックを積むボクセルゲーム風のピクセルアートで「ブロックがドカーンとくだけて四方八方に飛び散る」ようすを描いてください。草ブロック・土・石・金・ダイヤのブロックの大小のかけら（小さな立方体）が、画面のまん中から外側に向かって勢いよく飛んでいきます。かけらは画面の外側（上下左右のふち）に多く、まん中は広く空けて何も描きません。
1ドットがくっきりした大きな正方形に見えるように描きます。ぼかし・グラデーション・文字・背景の模様・影は入れません。どのかけらも外側を濃いこげ茶色のふちで囲みます。
```

加工：切り抜き（tol 30・穴も消す）→ 1ドット 11px で 250×140 に。

使い道：コンボ段階アップ・3コンボごと・FEVER 突入・FEVER 段階アップのカットインで、真ん中から外へ広がって消える（1.1 秒）。
