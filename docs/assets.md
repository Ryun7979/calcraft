# 素材の台帳（Gemini 製）

マシマシモードで使っている絵と音のうち、Google Gemini の **Web 画面**で作ったものの記録。API は使っていない（`docs/hade-mashimashi-playbook.md` §8）。
作り方の手順は `.claude/skills/gemini-assets/SKILL.md`。元の絵（JPEG）と未採用のものは `_inbox/`（git 管理外）にある。

- 作った日：2026-10-18（段階1：背景の柄・パーティクルの粒・ふきだしと札の枠・キャラの決めポーズ）
- 加工はすべて加工台 `scripts/asset-lab/`（`node scripts/asset-lab/server.mjs` → http://127.0.0.1:5199/）で行った。
  - Gemini のダウンロードは **JPEG**（2048×2048 前後）。ドット絵として使うため、**1マスの中央 40〜50% の平均色**で本物のドットに縮める（`pixelate`）。
  - 透過は「白い背景＋濃いふち」で頼み、ふちから白をたどって消す（`cutout`、tol 30〜40）。半透明は 110 を境に 0 か 255 にする（`hardAlpha`）。
  - ドットの大きさは、色の変わり目の間かくのいちばん多い値で見つける（加工台の `dotSize`）。
- 置き場所と読みこみ：`src/assets/hype/{tiles,parts,ui,pose}/`、`src/lib/hype/assets.ts`。

## 共通の頼み方

- 1枚ごとに新しいチャット（キャラの2枚目だけは、見本の絵を引き継ぐため同じチャット）。
- 小さなものは 2×2 のシート1枚で頼み、「4枚の間は白い余白で大きく離し、ます目の線は描かない」と書く。
- ドット絵は「16×16ドットのピクセルアートで、1ドットがくっきりした大きな正方形に見えるように」「ぼかし・グラデーション・影・文字・枠線は入れない」と書く。

## 1. 背景の柄（`src/assets/hype/tiles/`）

### tiles1 → grass / dirt / stone / cobble（16×16）

```
画像を作成してください。正方形の画像を2×2の4マスに分け、各マスに1枚ずつ、ブロックを積むボクセルゲーム風の「ブロックの表面テクスチャ」を描いてください。各テクスチャは16×16ドットのピクセルアートで、1ドットがくっきりした大きな正方形に見えるように描きます。ぼかし・グラデーション・立体の影・文字・枠線は入れません。各テクスチャは上下左右にくり返し並べてもつなぎ目が目立たない、マスいっぱいの平らな正方形にします。4枚の間は白い余白で大きく離し、ます目の線は描かないでください。
左上：草の生えた土の上面（あざやかな緑の草、明るい緑と暗い緑のドットのまだら）
右上：土（茶色、こげ茶とうす茶のドットのまだら）
左下：なめらかな石（灰色、明るい灰色と暗い灰色のドットのまだら）
右下：丸石（灰色の丸い石をすき間なく敷きつめた模様、暗い灰色のすき間）
```

加工：4マスを切り分け、ふちを 4px 落として 16×16 に縮める。石はくり返すと横すじが少し見える。

### tiles2 → ore-gold / ore-diamond / ore-emerald / ore-ruby（16×16）

```
左上：金の鉱石（灰色の石の地に、明るい黄色と金色の小さなかたまりが4〜5か所）
右上：ダイヤの鉱石（灰色の石の地に、明るい水色のかたまりが4〜5か所）
左下：エメラルドの鉱石（灰色の石の地に、あざやかな緑のかたまりが4〜5か所）
右下：赤い宝石の鉱石（灰色の石の地に、あざやかな赤のかたまりが4〜5か所）
```

加工：どの絵も同じ柄が 2×2 にくり返されていたので、32×32 に縮めて左上の 16×16 だけを使う。

### tiles3 → nether / magma / glow / amethyst（32×32）

（tiles1 と同じ前置きで）
```
左上：地獄の赤い岩（暗い赤とえんじ色のドットのまだら）
右上：マグマのブロック（黒っぽい岩のすき間から、あざやかなオレンジと黄色の溶岩が光る）
左下：光る石（明るい黄色とクリーム色とオレンジのドットのまだら、全体が光っている）
右下：紫の水晶のブロック（むらさき・ふじ色・白のドットの、きらきらした結晶）
```

加工：余白がせまかったので白のしきい値を 245 にして切り分け、32×32 に縮める（16 だとつぶれた）。

### tiles4 → planks / brick / tnt / leaves（32×32）

（tiles1 と同じ前置き。ただし「文字」は入れてよいことにして）
```
左上：木の板（明るい茶色の横長の板が4段、板の間に暗い線、木目のドット）
右上：赤いレンガ（赤茶色のレンガを互い違いに積み、すき間はうすい灰色）
左下：ばくだんの箱の側面（上と下が赤、まん中に白い帯、帯の上に黒い太い文字で「TNT」）
右下：木の葉っぱ（濃い緑と明るい緑のドットのまだら、ところどころに暗いすき間）
```

使い道：プレイ画面の背景はコンボ段階で stone → ore-gold → ore-diamond → ore-emerald、FEVER は magma（スキル「ギャラクシー」は amethyst）。リザルトは planks。タイトルのふってくるブロックは13種。

## 2. パーティクルの粒（`src/assets/hype/parts/`、20×20）

### parts1 → star / heart / coin / diamond

```
画像を作成してください。真っ白な背景に、ゲームのごほうびのエフェクトに使う小さなアイテムを2×2の4マスに1つずつ描いてください。それぞれ16×16ドットのピクセルアートで、1ドットがくっきりした大きな正方形に見えるように描きます。ぼかし・グラデーション・影・文字・背景の模様は入れません。どの絵も、外側を濃いこげ茶色の太いふち（1ドット）でぐるりと囲みます。4つの絵はお互いに大きく間をあけ、ます目の線は描かないでください。
左上：明るい黄色の五角の星（左上に白いつやのドット）
右上：あざやかなピンクのハート（左上に白いつやのドット）
左下：金色のまるいコイン（まん中に縦長の四角い穴の模様、白いつやのドット）
右下：水色のダイヤモンドの宝石（ひし形、白と青の面）
```

### parts2 → sparkle / note / emerald / block

（parts1 と同じ前置きで）
```
左上：きらきら光る4方向のひかり（十字の形の光、まん中が白く、先が細い黄色）
右上：水色の八分音符（はたのついた音符1つ）
左下：あざやかな緑のエメラルドの宝石（たて長の八角形）
右下：草の生えた土のブロックの小さなかけら（上が緑、下が茶色の、ななめから見た小さな立方体）
```

加工：切り抜き → 切りつめ → 正方形に余白を足す → 20×20 に縮める（16 は細部がつぶれ、24 は元とあまり変わらなかった）→ 半透明をなくす。

使い道：`FxCanvas` の `burst` の `sprites`。何も指定しないと star / sparkle を2割まぜる。花火は5つに1つ、紙ふぶきは3つに1つが絵。

## 3. ふきだし・札の枠（`src/assets/hype/ui/`）

### bubbles1 → bubble（54×22）/ shout（57×28）/ bang（57×34）/ plate（53×21）

```
画像を作成してください。真っ白な背景に、ゲームの「ふきだし」と「札」の枠を2×2の4マスに1つずつ描いてください。ピクセルアートで、1ドットがくっきりした大きな正方形に見えるように描きます。ぼかし・グラデーション・文字・背景の模様は入れません。どの枠も中はからっぽ（文字なし）にして、外側を濃いこげ茶色の太いふち（2ドット）でぐるりと囲みます。4つの絵はお互いに大きく間をあけ、ます目の線は描かないでください。
左上：白い横長の四角いふきだし（角は階段状に1段だけ丸める、ふちの内側に うすい灰色の影を1ドット、しっぽなし）
右上：あざやかな黄色の、ふちがギザギザのトゲトゲした叫びのふきだし（横長、トゲは10本くらい、しっぽなし）
左下：「ドカッ」の効果に使う爆発の形（赤いギザギザの星形の外側、中にオレンジ、まん中に黄色）
右下：金色の太いふちの横長の札（中はこげ茶色、ふちに光るつやのドット）
```

加工：切り抜き。1ドット ≒ 22.7px だったので、幅・高さを 22.7 で割ったドット数に縮める。

使い道：bubble はふつうのふきだし（`border-image` 9分割、1ドット 3px）、shout は大きなほめことば（のばして敷く）、bang は `FxCanvas.bang` の後ろ、plate はリザルトのミッション達成の札（9分割、1ドット 2px）。

## 4. キャラの決めポーズ（`src/assets/hype/pose/`）

見本の絵：`docs/character/preview.html` の待機ポーズのブロッくん・ブロッちゃんを白い背景に並べた PNG（1200×700）を添付した。

### pose1 → fever-boy（52×60）/ fever-girl（63×63）

```
画像を作成してください。添付の絵の2人のキャラクター（左：草ブロックの頭の男の子「ブロッくん」、右：ピンクのブロックの頭でツインテールの女の子「ブロッちゃん」）を、同じデザイン・同じ色・同じドット絵のタッチのまま描いてください。頭は四角いブロックで、目・口・服・色は添付の絵と同じにします。
ポーズ：2人がならんで、ゲームで大成功したときの決めポーズ。ブロッくんは片手のこぶしを高く突き上げてジャンプ、ブロッちゃんはピースサインをしてウインク。2人とも大よろこびの笑顔で、目は黄色い星のキラキラ。
横長の画像で、真っ白な背景にします。2人の絵の外側を濃いこげ茶色の太いふちで囲み、背景には何も描きません（文字・影・模様なし）。
```

### pose2 → rank-trophy（159×89）

（pose1 と同じチャットで）
```
画像を作成してください。さっきと同じ2人（ブロッくんとブロッちゃん）を、同じデザイン・同じ色・同じドット絵のタッチで描いてください。
ポーズ：ゲームの成績で最高ランクをとったときのお祝い。2人で大きな金色のトロフィーを1つ、両側から高く持ち上げている。2人とも口を大きくあけた笑顔で、目は黄色い星のキラキラ。
横長の画像で、真っ白な背景にします。2人とトロフィーの外側を濃いこげ茶色の太いふちで囲み、背景には何も描きません（文字・影・模様・紙ふぶきなし）。
```

加工：切り抜き（tol 30）→ 1ドット 14px として縮める（28px で割るとつぶれた）。pose1 は左右の2人に切り分けた。
pose2 には頼んでいない「No.1」の文字と星が入ったが、そのまま採用。トロフィーの取っ手の内側の白は、ふちに囲まれているので透明にならず残っている。

使い道：fever-boy / fever-girl は FEVER 突入のカットイン（`Cutins.tsx` の `BigPoses`）。rank-trophy はリザルトでランク S 以上のとき上から飛びこむ（2.6 秒）。
